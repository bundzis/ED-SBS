# ROMS Repo
This repo contains raw sourcecode from a forked version of ROMS (https://github.com/bundzis/roms/tree/develop). The purpose of this code is to pull things from ROMS/CSTMS and add it into MITgcm as a package that can be used in simulations. 

(22/10/2026) This only contains the Sediment code from ROMS/Nonlinear/Sediment so far with plans to look first at sediment settling and fluxes.
